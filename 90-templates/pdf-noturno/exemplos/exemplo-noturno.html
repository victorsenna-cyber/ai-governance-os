PDF noturno

A folha escura original da casa: fundo grafite, texto claro, destaque cobre, títulos em Palatino e corpo em Lato. Desde 16/10/2026 ela só sai quando o operador pede. O padrão é o elétrico, que roda por cima desta mesma folha.

Exemplar · 1 de novembro de 2026 · 90-templates/pdf-noturno

O que é este modelo

Uma folha de estilo única, escura, que leva para o PDF a leitura que o Markdown tem quando renderizado. Nasceu porque o .md aberto num bloco de notas vira texto cheio de sinais.

2tons de folha: escuro para entender, claro para assinar
3classes de documento: estrutura, decisão e formal
1folha de estilo para todos os documentos, sem CSS por documento
Pergunta do leitorClasseGerador
"Como isso funciona?"Estruturaesta folha, com o diagrama abrindo cada seção
"Por que eu faria isso?"Decisãoesta folha, com a economia no eixo
"Eu assino?"Formalo PDF claro, não este
Documento que se lê para entender vai no escuro. Documento que se lê para assinar vai no claro.

A classe se escolhe pelo estado do leitor, antes do gerador. Quem ainda não vê o mecanismo recebe estrutura.

O diagrama abre, o texto detalha.

Como ele se gera

O HTML carrega a folha, o Chrome sem interface imprime e o conferidor aprova ou reprova. Reprovado não se entrega.

O retorno tracejado é a régua de 01/11/2026: defeito achado no PDF se corrige no modelo, não só no documento.
