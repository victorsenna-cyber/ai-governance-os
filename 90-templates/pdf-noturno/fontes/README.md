# Fontes

Arquivos estáticos, de propósito: a fonte variável pelo link do Google entra no PDF do Chrome como Type3, e o PDF abre quebrado.

Anton, Inter, Lato e Montserrat estão sob a **SIL Open Font License 1.1** (https://openfontlicense.org), distribuídas pelo Google Fonts. Podem ser usadas, embutidas e redistribuídas; não podem ser vendidas sozinhas.
